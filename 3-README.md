# GTA 6 Trophy Guide + Tracker

A static web app to track your progress for the 55 official PS5 GTA VI trophies.

## Features

- Complete list of 55 trophies.
- Progress tracking with local storage.
- Filters by grade and type.
- Spoiler protection.
- Platinum roadmap.
- Guide tips.
